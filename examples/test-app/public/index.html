🐛 CDP-TOOLS Debugger Test Application

Welcome! This application contains 8 debugging challenges. Each challenge requires specific CDP tools to solve!

Challenge 1: DOM Manipulation Bug 🔍

The "Fetch User" button in challenge 2 below doesn't work - why?

Hint: Use querySelector, findClickable, or getProperties to inspect the DOM

Challenge 2: Network Request Bug 🌐

Fetch user data - but something's wrong with the response!

Hint: Use network list, network get to check status codes and response bodies

Challenge 3: Console Error Hunt 📋

Process some data - there's an off-by-one bug hiding in the console!

Hint: Use console search to find warnings with pattern "WARN"

Challenge 4: Runtime Data Corruption 🧮

The server sends correct pricing data, but something corrupts it during processing!

Hint: Set breakpoints in applyDiscountRules and calculateWithRules. Use getVariables to watch how values change. The server data is correct - the corruption happens client-side!

Challenge 5: localStorage Bug 💾

Store and retrieve data from localStorage - but it's not working correctly!

Hint: Use storage getLocalStorage to inspect what key was actually used

Challenge 6: Hidden Debug Mode 🔓

There's a secret code hidden in this app - but you need debug mode to see it!

Hint: Use evaluateExpression to enable appState.debugMode = true, then try again

Challenge 7: Secret Vault Password 🔐

Find the password that unlocks the vault - but it's never logged completely!

Hint: Use setLogpoint (not breakpoint!) in constructVaultPassword() to observe password being built character by character

Challenge 8: State Mutation Bug 🔬

A shared state object passes through 4 functions - one of them corrupts it!

Hint: Use breakpoint set + stepInto to trace through the chain. Watch sharedState.multiplier - it gets corrupted somewhere! Use getVariables at each step.

Bonus: Performance Check ⏱️

This request is really slow - can you find it in the network requests?

Hint: Use network search to find requests over 2000ms
